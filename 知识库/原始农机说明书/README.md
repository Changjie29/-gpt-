# 原始农机说明书

按品牌、型号存放已有的完整说明书、操作/维保手册、交机培训及来源记录。资料种类和适用范围以[来源索引](../整理后的知识库/农用拖拉机知识库/sources.json)为准；培训资料不等同于整机说明书。

- 保留完整原件，整理内容存入同级的「整理后的知识库」目录。
- 建议按品牌和型号建立子目录，文件名注明手册名称和版本。
- 示例：品牌/型号/型号_操作说明书_版本.pdf。

新取得但仅保存公开链接的资料，目录内放`来源记录.md`，注明手册编号、版本、原链接、实际取得时的PDF哈希/字节数/页数及已核对范围。例如[东方红LF1504](东方红/LF1504/来源记录.md)。记录文件的哈希与PDF哈希分别保存。

人读事实及证据见[品牌目录](../整理后的知识库/农用拖拉机知识库/README.md)。未取得正文的候选见[采集记录](../整理后的知识库/农用拖拉机知识库/采集记录/)，后续新增遵循[整理规范](../条目整理规范.md)。
