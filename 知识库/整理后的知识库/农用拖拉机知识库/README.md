## 知识使用与整理规则

1. 先匹配品牌、完整型号、排放/动力、出厂配置、市场、手册及控制软件版本；无法匹配时返回“资料不足/适用性待核实”。
2. PDF记录页序和印刷页码；网页记录原网址、章节/编号及快照校验值。不要给网页伪造PDF页码。
3. 故障可能原因不等于确诊；记录现象、检测结果、反证和所需检测，不根据单一症状直接建议更换部件。
4. 精确油品、容量、扭矩、压力、线束和故障码只有经对应手册确认后才能录入；不跨机型拼接。新闻报道只用于机型背景。
5. 智能系统分清“辅助自动导航”“有人监护”“整机无人作业”；不能因为安装导航就认定具备全无人、避障或失联安全能力。
6. 记录四种状态：已取得完整手册、已取得正文补充、仅发现来源、待核实。采集日期不等于手册出版日期。
