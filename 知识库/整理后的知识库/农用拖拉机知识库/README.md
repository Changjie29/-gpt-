## 知识使用与整理规则

1. 先匹配品牌、完整型号、排放/动力、出厂配置、市场、手册及控制软件版本；无法匹配时返回“资料不足/适用性待核实”。
2. PDF记录文件页序与印刷页码；网页记录原网址、章节/编号及快照哈希。上传时间、PDF创建时间与手册出版日期分别记录。
3. 故障可能原因不等于确诊；记录现象、检测结果、反证和所需检测，不根据单一症状直接建议更换部件。
4. 精确油品、容量、扭矩、压力、线束和故障码须由对应手册及配置确认，不跨机型拼接。
5. 辅助自动导航、有人监护、整机无人作业分别标记；配套导航系统手册不能替代鸿鹄等无人整机手册。
6. 扫描资料和编码异常资料先做索引，经OCR/文字修复与逐页复核后再提炼操作知识；原件异常字段保留，不擅自修正。
