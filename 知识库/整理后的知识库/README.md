# 整理后的知识库

存放根据「原始农机说明书」中的完整资料整理的各个知识库，使用 Markdown 格式。

- 按品牌、型号或主题建立子目录，分别整理操作方法、维护保养、故障排查和技术参数等内容。
- 每份知识文档注明原始文件路径、手册版本、对应章节或页码，便于追溯。
- 无法从原文确认的内容标记为「待核实」，不补造参数或操作步骤。
- 本目录用于资料整理与归档。平台保留 `server/knowledge/` 的通用知识，并通过 `农用拖拉机知识库/entries.jsonl` 加载本目录中已列入统一索引的编号条目；未列入索引的文档、README、待补资料及原始 HTML/PDF 不自动参与检索。

## 证据与使用规则

1. 先确认品牌、完整型号、市场、配置和手册版本；无法匹配时返回「资料不足／适用性待核实」，不能直接套用相近型号。
2. 每个条目保留来源编号、章节、PDF 页序和印刷页码。PDF 页序从封面起按 1 计数；印刷页码以页面页脚为准，二者不可混淆。
3. 「已对照原文」表示整理内容与选定手册页面核对过，不表示厂家复核、实车验证或已确诊。故障表提供的是可能原因，不是检测结论。
4. 操作前阅读该机型的安全条目；保养表是选摘，不替代完整计划、磨合期项目、特殊工况要求或厂家更新。小时与日历周期并列且原文规定先到者时，不能只按小时计算。
5. 涉及喷油系统、带压液压、电气内部检修以及制动等安全部件，由合格维修人员按对应原手册处理。文中「整理安全边界」是保守使用限制，不伪装成厂家原句。
6. 油品牌号、容量、扭矩、压力阈值、线束脚位及控制器通用代码未在本批系统整理；不能从其他品牌补齐。模糊、冲突或未核对的字段保留「待核实」。
