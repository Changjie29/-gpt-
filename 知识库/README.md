```mermaid
flowchart LR
  A[原件或公开来源] --> B[来源索引 sources.json]
  B --> C[人读知识卡：编号、事实、证据]
  C --> D[机器条目索引 entries.jsonl]
  D --> E[型号及排放过滤、关键词检索]
  E --> F[AI或本地回答：附来源和限制]
```

140条包含资料索引、核验和缺口信息，不代表140条维修结论。新取得的东方红LF1504已完整核验文件和选定正文页，GitHub保存原链接、来源记录和10条自行概述，未上传整册。其他资料的已审范围和待审正文可从各知识卡追溯。

## 检查与接入

从仓库根目录执行：

```bash
python3 知识库/工具/校验索引.py
npm test
npm run build:server
npm run dev
```

修改索引后重新加载服务，检查`GET /api/health`中的`archivedEntries`是否等于JSONL条数；当前为140条，加9个通用片段共149个片段。再按已记录的品牌/完整型号提问，确认回答保留条目编号、原文页、版本与适用限制。未知机型、排放不匹配或缺少证据时说明资料不足。

原件完整取得、选页核对、GitHub保存和网站部署分别验收。未取得正文的候选及尚未核对的目录不能用于生成操作或诊断参数。
